# ✂️ VideoCut Studio

**Fast, on-device video cutting, compression, joining & rotation for Android**

No upload. No cloud processing. Everything runs locally via MediaCodec & FFmpeg.

## 🧰 Features

| | Tool | What it does |
|---|---|---|
| ✂️ | **Cut Video** | Trim a single range, frame-precision preview, fine-tune, visual timeline strip |
| 🗑️ | **Remove Multiple Parts** | Select several ranges, cut them all out in one pass |
| 🧩 | **Keep Multiple Parts** | Select several ranges, merge them into one output |
| 🗜️ | **Video Compressor** | H.264 / HEVC / custom target size / lossless stream copy |
| 🔗 | **Join Video** | Merge clips, reorder, per-clip rotate, auto re-encode detection |
| 🔄 | **Rotate Video** | Rotate/flip full video or specific time ranges independently |

<br>

### 🗜️ Compressor detail

| Option | Detail |
|---|---|
| **H.264 (CRF)** | Universal compatibility |
| **HEVC/H.265** | Up to 50% smaller at similar quality |
| **Target File Size** | Custom MB or percentage |
| **Lossless / Fast Seek** | Instant stream-copy remux, ~0–5% loss |
| **Presets** | Ultrafast · Fast · Medium · Slow |
| **Resolution** | Original · 1080p · 720p · 480p · 360p |
| **Preview** | Live output size estimate before processing |

<br>

## ⚙️ Settings

- 🎨 6 static color themes + 6 mixed accent themes
- 🔋 Battery optimization exemption for reliable background jobs
- 📶 Foreground processing service + CPU wake lock toggle for long transcodes
- 📁 Configurable output directory
